## Request Flow (İstek Akışı)

```
1. KULLANICI İSTEĞİ
   │
   ▼
2. NGINX (SSL Termination)
   │
   ├──► /static/* ──► Dosya Sistemi
   │
   └──► /api/* ──► FastAPI
                    │
                    ▼
3. MIDDLEWARE
   ├── CORS
   ├── Auth (JWT Validation)
   └── Rate Limiting
                    │
                    ▼
4. ROUTER
   ├── Path Matching
   └── Dependency Injection
                    │
                    ▼
5. ENDPOINT HANDLER
   │
   ├──► Redis Check (Cache Hit?) ──► Return Cached
   │
   └──► Database Query
        │
        ▼
6. RESPONSE
   ├── Serialize (Pydantic)
   ├── Cache Update (Redis)
   └── Return JSON
```
