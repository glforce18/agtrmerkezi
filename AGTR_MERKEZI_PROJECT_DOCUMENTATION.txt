================================================================================
                              1. GENEL BAKIS
================================================================================

AGTR Merkezi, Half-Life ve Counter-Strike 1.6 oyunculari icin gelistirilmis
kapsamli bir topluluk platformudur. Platform, oyun sunucusu yonetimi, forum,
turnuva sistemi, sanal cuzdan, klan yonetimi ve daha bircok ozellik sunar.

CANLI SITE: https://agtrmerkezi.com
TEKNOLOJI: Vue.js 3 (Frontend) + FastAPI (Backend) + MySQL + Redis

================================================================================
                           2. TEKNOLOJI STACK
================================================================================

BACKEND:
--------
- Python 3.13
- FastAPI (Modern, async web framework)
- SQLAlchemy (ORM)
- Pydantic (Data validation)
- PyMySQL (MySQL driver)
- Redis (Caching, session, rate limiting)
- Jose (JWT token)
- Passlib + bcrypt (Password hashing)
- APScheduler (Scheduled tasks)
- WebSockets (Real-time communication)
- Uvicorn (ASGI server)

FRONTEND:
---------
- Vue.js 3 (Composition API)
- Vite (Build tool)
- Pinia (State management)
- Vue Router 4 (Routing)
- Naive UI (Component library)
- Axios (HTTP client)
- Chart.js (Grafikler)
- WebSocket API (Real-time)

VERITABANI:
-----------
- MySQL 8.0 (Ana veritabani)
- Redis 7.x (Cache, session, queue)

DEVOPS:
-------
- Systemd (Process management)
- Nginx (Reverse proxy)
- Let's Encrypt (SSL)
- Docker (Opsiyonel deployment)
